## 2️⃣ 주요 기능

### 🕹️ 핵심 게임 플레이

* 플레이어는 하단에 위치한 우주선을 좌우 이동하며 적을 격추.
* 적군(벌레 형태의 에일리언)은 웨이브 단위로 등장.
* 적이 돌진하거나 탄환을 발사함.
* 플레이어는 **스페이스바** 또는 **마우스 클릭**으로 탄환 발사.
* 점수를 획득하고, **최고 점수(High Score)**가 로컬스토리지에 저장됨.

### 💥 스테이지 및 난이도

* **Stage 1~10** 구성 (점점 속도와 적의 패턴 증가)
* 각 스테이지 마지막에는 **보스 캐릭터 등장**
* 플레이어가 격추되면 **Game Over → 재시작 버튼** 표시

### ⚙️ 게임 시스템

| 요소          | 설명                 |
| ----------- | ------------------ |
| **플레이어 이동** | 좌우 키 또는 터치 스와이프    |
| **공격**      | 스페이스바 또는 클릭        |
| **라이프**     | 기본 3개, 0이 되면 게임 종료 |
| **스코어**     | 적 종류별로 점수 차등 부여    |
| **보스전**     | 일정 HP 보유, 패턴형 공격   |

## 3️⃣ 기술 스펙

### 🔧 Frontend

* **React 18+**
* **TypeScript**
* **Canvas API** (HTML5 기반 2D 렌더링)
* **Framer Motion** (UI 애니메이션 효과)
* **zustand** (게임 상태 관리)
* **TailwindCSS** (UI 스타일링)
* **Vite** (번들러)

### 🧩 구조 개요

```
src/
 ├─ components/
 │   ├─ GameCanvas.tsx         // 메인 게임 로직 (Canvas)
 │   ├─ Player.ts              // 플레이어 객체
 │   ├─ Enemy.ts               // 적 객체
 │   ├─ Bullet.ts              // 탄환 로직
 │   ├─ UIOverlay.tsx          // 점수, 생명 표시
 │   └─ GameOverModal.tsx      // 게임 종료 화면
 ├─ store/
 │   └─ useGameStore.ts        // 전역 상태 관리
 ├─ assets/
 │   └─ sprites/               // 픽셀 이미지, 사운드
 ├─ hooks/
 │   └─ useGameLoop.ts         // requestAnimationFrame 기반 루프
 ├─ App.tsx
 └─ main.tsx
```

## 🚀 설치 및 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

브라우저에서 `http://localhost:5173` (또는 표시된 포트)로 접속하세요.

### 3. 빌드
```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

### 4. 조작 방법
- **이동**: ← → 방향키 또는 A/D 키
- **발사**: 스페이스바 또는 마우스 클릭
- **목표**: 모든 적을 격추하고 최고 점수를 달성하세요!
